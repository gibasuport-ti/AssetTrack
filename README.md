# Coletor qrcode - Controle de Ativos
### Rede Corporativa Cirion Technologies (Uso Interno Exclusivo)

Este aplicativo foi desenvolvido para gestão interna de ativos e inventário patrimonial da **Cirion Technologies**, operando com autenticação corporativa Microsoft 365, Microsoft Authenticator (MFA) e integração com SharePoint Online.

> **Importante**: Este sistema é de uso estritamente corporativo interno na infraestrutura e rede da Cirion Technologies, não sendo publicado em repositórios públicos ou GitHub.

## Execução na Intranet / Servidores Corporativos

**Pré-requisitos:** Node.js 18+

1. Instalar dependências:
   ```bash
   npm install
   ```
2. Iniciar servidor da aplicação:
   ```bash
   npm run dev
   ```
3. Build para produção interna:
   ```bash
   npm run build
   npm start
   ```
